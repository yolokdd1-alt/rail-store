# RAIL — демонстрационный магазин одежды

Фотографическая вешалка с выбором вещей, плавной сменой фронтального и бокового ракурсов, свайпами и управлением с клавиатуры. Карточки товара и локальная демо-корзина. Оплата и отправка заказов не подключены.

Сайт: https://yolokdd1-alt.github.io/rail-store/

## Локальный запуск

```sh
python3 -m http.server 4173 --directory docs
```

## Проверка анимации

```sh
node tests/photo-motion.mjs
```

## Публикация

GitHub Pages публикует папку `docs` из ветки `main`. После отправки изменений сайт обновляется автоматически.

Изображения демонстрационные и созданы с помощью ImageGen. Ракурсы смонтированы в 2D; 3D-моделей нет.
